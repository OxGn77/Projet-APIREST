Avant d'utiliser, merci de faire dans le terminal npm init, puis npm run

Il vous faudra un fichier .env avec :
PORT=3001
JWT_SECRET=
DB_PORT=8889 (MAC) ou 3306 (Windows)
DB_HOST=localhost
DB_USER=
DB_PASSWORD=
DB_Name=

Il faudra crée une base de donnes dans MySQL en s'y connectant. Il faudra mettre le nom dans "DB_Name" ainsi que les informations utilisateurs dans DB_USER et DB_PASSWORD

Le JWT_SECRET est aussi à rentrer, n'hésitez pas à aller en chercher un sur internet.
